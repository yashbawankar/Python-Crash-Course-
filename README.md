About the Book
Python Crash Course is a fast-paced, thorough introduction to Python that will have you writing programs, solving problems, and making things that work in no time. It is divided into two parts:

Part 1: Basics – Covers fundamental programming concepts (lists, dictionaries, classes, testing).

Part 2: Projects – Includes a Space Invaders-style game, data visualization with various libraries, and a simple web app.

🚀 Getting Started
To run the scripts in this repository, ensure you have Python installed.

Clone the repository:

Bash
git clone https://github.com/yashbawankar/Python-Crash-Course-.git
Navigate to a specific chapter:

Bash
cd "Part 1 Basics"
Run a script:

Bash
python filename.py
